# Taska Frontend

Premium Business Operating System by Result Seekers

## Setup

```bash
# Install dependencies
npm install

# Development
npm run dev

# Build
npm run build

# Preview
npm run preview
```

## Stack

- React 19
- Vite 8
- TailwindCSS 4
- TanStack Query 5
- React Router 7

## Key Packages

- `@tanstack/react-query` - Data fetching
- `zustand` - State management
- `react-hook-form` + `zod` - Form validation
- `lucide-react` - Icons
- `recharts` - Charts
- `date-fns` - Date utilities

## Project Structure

```text
src/
|- components/    # Reusable components (Layout, Logo, ErrorBoundary)
|- hooks/         # Custom hooks (useOnlineStatus)
|- lib/           # Utilities (api, config, validation)
|- pages/         # Page components
|- stores/        # Zustand stores (authStore)
`- App.jsx        # Main app with routing
```
